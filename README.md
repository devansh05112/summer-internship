# 🧠 Cerebra AI

An AI-powered study assistant built using **Python**, **Flask**, and the **Groq LLM API** that helps students learn smarter by transforming PDF notes into summaries, quizzes, flashcards, and interactive AI conversations.

---

## 🚀 Features

### 📄 PDF Upload
- Upload PDF study material
- Automatic text extraction
- Secure file validation

### 📝 AI Summary
- Generate concise summaries
- Highlight key concepts
- Save study time

### ❓ AI Quiz Generator
- AI-generated MCQs
- Instant scoring
- Accuracy analysis
- Performance feedback
- Explanations for every answer

### 📊 Quiz Report
- Download professional PDF reports
- Pie chart performance analysis
- Detailed question review
- Correct/Wrong/Skipped statistics

### 💬 Chat with Notes
- Ask questions directly from uploaded notes
- AI-powered explanations
- Markdown-formatted responses
- Copy answers
- Suggested prompts
- Modern chat interface

### 🧠 AI Flashcards
- Automatically generated flashcards
- Flip animation
- Previous/Next navigation
- Shuffle cards
- Progress tracking
- Favorite cards
- Mark cards as mastered
- Mobile swipe support
- Completion screen

### 📚 My Notes
- View uploaded PDFs
- Search notes
- Manage study materials

### 📜 History
- Track previous study sessions
- View summaries
- View quizzes
- View flashcards
- Resume AI chats

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Cerebra-AI.git
```

Move into the project

```bash
cd Cerebra-AI
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate it

### Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
